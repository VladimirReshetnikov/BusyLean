# BusyLean Contender 7 research bundle

This bundle proposes **Contender 7: autonomous operator reflection** for
[VladimirReshetnikov/BusyLean](https://github.com/VladimirReshetnikov/BusyLean),
based on repository commit `86b360648163f0249eab79539438b6a83dfe8215`.

The central definition is:

```lean
def autonomousTransformer : Transformer :=
  operatorStage reflectionTransformer index

def autonomousFamily : Family :=
  autonomousTransformer p5Family

def contender_7 : Nat := autonomousFamily 42 42
```

`operatorStage` lifts Contender 6's reflection from oracle families to
transformers of oracle families, and iterates that lift along the same universal
W-tree `index`.  The included proof source gives `contender_6_lt_contender_7` by explicit
child inclusion, without assuming oracle monotonicity. It also gives the
pointwise strengthening `finalFamily n < autonomousFamily n n` and eventual
domination of every operator stage generated by a W-language-defined tree.
Kernel acceptance remains the final integration gate, as described below.

## Contents

- `article/contender7.tex`, `article/contender7.pdf`: research article.
- `repo_overlay/`: files to copy over a checkout of BusyLean, including a
  repository-facing `CONTENDER7.md`.
- `patches/contender7.patch`: unified patch against the recorded base commit.
- `scripts/static_audit.py`: source-level rule and dependency audit.
- `scripts/check_contender7.py`: clean-build/timing/axiom check for a merged tree.
- `validation/`: static validation report, manual Lean review, PDF checks,
  patch-application record, and checksums.

## Integration

From a checkout at the recorded base commit:

```bash
git apply patches/contender7.patch
python3 scripts/check_contender7.py
```

Alternatively copy the contents of `repo_overlay/` into the repository root.
