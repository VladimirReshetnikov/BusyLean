## The proposed integer

Let `T_W` have types generated by

```
A, B ::= Nat | A -> B | W A
W A ::= leaf | node (A -> W A)
```

The arrow production has two independently chosen child types. The language includes
the original raw term constructors, natural recursion at every represented
type, and tree constructors/structural recursion. Oldest-first variable levels,
error defaults, and the original arrow casts are retained.

Let `M_W(n)` be the largest natural score of any raw term of depth at most `n`.
Define

```
B(n)       = 1 + max(n, M_W(n), 2^(n+1))
I(f,0,x)   = x
I(f,k+1,x) = I(f,k,f(x))
A_f(0,n)   = f(n)
A_f(k+1,n) = A_f(k,n) + I(A_f(k,.),n+1,n+1) + 1
J(f)(n)    = A_f(n,n)
R_0        = B
R_(k+1)    = J(R_k)
F(n)       = R_n(n)
N          = I(F,42,42)
```

The actual Lean source keeps the redundant guard
`max(oldMaximum n, wMaximum n)` inside the seed. The article proves this equals
`wMaximum n`; the guard makes the short strict-comparison certificate independent
of mechanizing enumeration inclusion. The independent definition above never
mentions the previous named integer.

The proved bound is

```
N > Tower(C5) > C5,  where C5 = original maximum at depth 42.
```

The short comparison uses

```
C5 < B(42) <= F(42) <= I(F,41,F(42)) = N.
```

Every fixed unary object-language program `q` of depth `d` denotes a function
`g` satisfying `g(n) <= M_W(n) < B(n)` for `n >= max(32,d+1)`. Thus neither the
seed nor the diagonal is uniformly representable in that same object language.
This is a statement about functions, not an assertion that a particular integer
has no numeral. No proof-theoretic ordinal calibration or global optimality is
claimed. The article gives seven further research targets.

## Perform the still-pending Lean validation

Install the pinned native toolchain, then run:

```sh
python3 scripts/check_lean.py
```

The script runs Lean in `lean/`, checks the compiler version, sets the local
module path, and checks these modules in order:

```sh
lean -o BigNumber/Definitions.olean BigNumber/Definitions.lean
lean -o BigNumber/Proofs.olean BigNumber/Proofs.lean
lean BigNumber/Audit.lean
```

Use the Python script rather than copying these raw commands to retain the
module-path setup and the timing/axiom gates. It exits unsuccessfully if the
compiler is missing, compilation fails, a limit is exceeded, or the expected
empty-axiom reports are absent. Native toolchain installation and prebuilt
standard-library installation are outside the timing gates. Compilation loads
prebuilt `Init`; only the proof phase imports the newly checked definitions.
The emitted report includes the actual stdout, stderr, return codes, and times.

**Do not run `#eval contender_6`, or request its decimal expansion.** The contest
tests the time to check a symbolic definition and its comparison proof, not the
time required to normalize the named integer.
